# 从一次复制，到另一端可粘贴

Mac 使用 AppKit 观察原生剪贴板
Windows 使用 WPF 托盘和原生剪贴板接口
Windows 是唯一的 HTTPS 监听端，Mac 直传并轮询反向内容

1. 观察新复制，发出带顺序号与会话标识的任务
2. 文件先生成稳定快照，分块处理，避免直接传输还在变化的源文件
3. 通过 HTTPS 直连，校验设备证书、主机名和固定公钥
4. 接收后检查长度与 SHA-256
5. 再检查是否有新复制抢先，符合条件才写入系统剪贴板

新的本机复制会撤销旧任务
启动、恢复和重连只记录基线，等待用户新复制
收到的文件持久保存，退出不会把引用它们的文档弄坏

Mac 网络传输使用系统自带 curl，不修改系统全局代理
敏感配置通过标准输入传给 curl，不放在进程参数和环境变量
长期令牌分别保存在 Keychain 和当前 Windows 用户的 DPAPI 保护区

图片内容与图片文件是两条路径
图片文件保留原字节；图片内容输出系统可识别格式
Windows同时提供PNG、DIBV5和传统24位DIB，以兼容AutoCAD等软件

协议请求结构见 `protocol/v1/requests.schema.json`
本工具没有服务器中转、没有公网账户，也不会自动打开或执行接收文件
