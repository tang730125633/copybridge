# 给第一次使用 CopyBridge 的人

当前交付形式为本地试用包，Windows 界面 v0.4.2，Mac 客户端 v0.3.2
两端继续使用原有配对与同步协议

## 用户实际走的路径

1. 收到整份试用包，打开「从这里开始.html」
2. 在各自电脑解压对应版本，打开程序
3. 两台电脑处于同一个可信网络
4. Windows 点击「复制连接信息」，复制地址与短口令
5. 通过自己的聊天等可信方式，把这一行信息带到 Mac 并复制
6. Mac 点击「粘贴连接信息」，两项自动填好，再点击「连接」
7. 先做一次文字复制粘贴，再交换方向尝试
8. Windows 可从「使用指南」添加桌面快捷方式

两端使用统一的蓝色双箭头图标
重启后在两台电脑各打开 CopyBridge，程序沿用原配对尝试连接
看到已连接后，需要重新复制一次；关闭窗口与退出程序是不同操作

Windows 必须完整解压，不能只取出 exe 或直接在压缩包内运行
程序已包含运行所需组件，用户不需要自行构建代码
Mac 包面向 Apple 芯片，本次没有提供 Intel 构建

## 窗口如何引导

未配对时，首页只给出一个主要动作「连接我的 Mac」
连接页只展示 Windows 地址和短口令，一键复制
Mac 直接粘贴整行并连接，旧文件方式折叠保留

已配对后，首页显示两台设备与当前状态
重新配对和断开操作收进「更换或断开设备」
这些操作保留确认提示，避免把现有连接误当成首次设置

设置页保留显式保存和设置版本冲突处理
使用指南解释启动、配对、首次验证、桌面入口与使用边界

## 分享包的范围

只打包 publish 产物、Mac 应用包和用户说明
禁止加入运行数据目录、配对文件、密钥、诊断日志和收到的文件
每位使用者必须在自己的两台设备上创建独立配对

发布前检查压缩包的全部条目，确认没有用户配置和凭据
程序自检应在发布目录之外运行，避免结果文件混入包内

## 当前仍有的门槛

- 尚未完成 Windows 正式签名和 macOS 公证，不能宣传为无提示安装
- 新电脑首次启动、系统网络授权与全新配对，仍需独立实机验收
- 只有当前 Windows 与 Apple 芯片 Mac 的验证，未覆盖其他系统和网络
- 网络地址变化的恢复体验沿用现有逻辑，本次没有重做设备发现
- 试用包不自动配置开机启动；两端需要自行打开程序

本次没有公开发布、发送给第三方或改变防火墙规则
